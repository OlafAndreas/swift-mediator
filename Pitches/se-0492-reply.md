For anyone following this thread: the "unified runtime API for reading section contents" that SE-0492 lists under Future Directions is now pitched separately, as [[Pitch] Runtime enumeration of custom sections](https://forums.swift.org/t/pitch-runtime-enumeration-of-custom-sections/90011). It proposes one runtime entry point that returns a named section's contents from every loaded image on each object format, with an observer for images loaded later, and comes with a library prototype ([swift-sections](https://github.com/OlafAndreas/swift-sections)) that shows how far a library can get today and where only the toolchain can help, in particular on ELF, where the `swift5_sections` index described in SE-0492 is not emitted by the 6.4 toolchain. Feedback is welcome in the pitch thread.
